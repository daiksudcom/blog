# Blog

`blog.daiksud.com` の記事一覧、タグ一覧、記事ページ、フィード、発見可能性、キャッシュの振る舞いを定義するリポジトリです。

## 現在の状態

実装開始前の基準として、観測可能な振る舞いを Gherkin、技術的な決定を Architecture Decision Records（ADR）で確定しています。
